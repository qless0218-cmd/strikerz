# StrikerZ

StrikerZ is a browser-playable carrom game prototype with a lightweight Node.js server.

## Run locally

- Node.js 20 or newer
- `npm start`
- Open `http://localhost:3000`

## Health check

- `GET /health`
- `GET /api/health`

The game is an early prototype. Test gameplay across browsers and devices before treating it as production-ready.
